## 阅读前只需要知道这些

你只需要会：

- 字符串下标与子串；
- `std::sort` 的基本用法；
- 什么是字典序；
- 倍增的直觉：长度从 $1$ 变成 $2$、$4$、$8$……

全文统一使用 **0-based 下标**。字符串 $s$ 的长度记为 $n$，`s[i..]` 表示从位置 $i$ 开始一直到结尾的后缀。

## 一、后缀数组到底是什么

### 1.1 什么是后缀

字符串 `banana` 一共有 $6$ 个非空后缀：

| 起点 $i$ | 后缀 `s[i..]` |
|:---:|---|
| 0 | `banana` |
| 1 | `anana` |
| 2 | `nana` |
| 3 | `ana` |
| 4 | `na` |
| 5 | `a` |

把它们按字典序从小到大排序：

```text
a < ana < anana < banana < na < nana
```

对应的原串起点依次是：

```text
5, 3, 1, 0, 4, 2
```

这串起点就是后缀数组：

$$
sa=[5,3,1,0,4,2].
$$

### 1.2 `sa[i]` 的人话解释

`sa[i]` 回答的是：

> 字典序第 $i$ 小的后缀，从原串哪个位置开始？

例如：

- `sa[0] = 5`：最小后缀是 `s[5..] = "a"`；
- `sa[2] = 1`：第 2 名（从 0 开始）是 `s[1..] = "anana"`；
- `sa[5] = 2`：最大后缀是 `s[2..] = "nana"`。

所以 `sa` 的**下标是排名**，值是**原串位置**。

## 二、`sa` 与 `rk`：一对互逆映射

只知道“第几名从哪里开始”还不够。我们经常还会反过来问：

> 从位置 $i$ 开始的后缀，排在第几名？

这就是排名数组 `rk`：

$$
rk[i]=s[i..]	ext{ 在全部后缀中的排名}.
$$

对 `banana`：

```text
位置 i       0  1  2  3  4  5
后缀         banana anana nana ana na a
rk[i]        3  2  5  1  4  0
```

因此：

```text
sa = [5, 3, 1, 0, 4, 2]
rk = [3, 2, 5, 1, 4, 0]
```

二者互为逆映射：

$$
sa[rk[i]]=i,\qquad rk[sa[r]]=r.
$$

## 三、倍增算法：不直接比较长后缀

### 3.1 暴力排序为什么不够快

最直接的写法是把 $0,1,\dots,n-1$ 放进数组，然后按 `s.substr(i)` 排序。一次比较最坏要扫 $O(n)$ 个字符，排序又需要 $O(n\log n)$ 次比较，总复杂度会到：

$$
O(n^2\log n).
$$

我们真正需要解决的问题是：**怎样用已经知道的短前缀排名，快速得到更长前缀排名？**

### 3.2 倍增的核心不变量

假设某一轮开始时，`rk[i]` 已经表示后缀 `s[i..]` 的**前 $w$ 个字符**的排名。

那么前 $2w$ 个字符可以拆成两段：

$$
s[i..i+2w)=s[i..i+w)+s[i+w..i+2w).
$$

第一段的排名是 `rk[i]`，第二段的排名是 `rk[i+w]`。因此我们不必比较 $2w$ 个字符，只需比较二元组：

$$
\big(rk[i],\ rk[i+w]\big).
$$

如果 `i+w >= n`，第二段不存在。我们把它记为 $-1$，让“已经结束的后缀”排在还有字符的后缀前面。

这就是倍增法的归纳：

1. 初始 $w=1$，一个字符的排名当然可以直接得到；
2. 已知长度 $w$ 的排名，用排名二元组排出长度 $2w$ 的顺序；
3. 令 $w\leftarrow 2w$，重复；
4. 当所有后缀排名都不相同，或者 $w\ge n$ 时结束。

### 3.3 手推 `banana` 的三轮

初始按单个字符排名，`a < b < n`：

| $i$ | 字符 | $w=1$ 时的旧排名 |
|:---:|:---:|:---:|
| 0 | `b` | 1 |
| 1 | `a` | 0 |
| 2 | `n` | 2 |
| 3 | `a` | 0 |
| 4 | `n` | 2 |
| 5 | `a` | 0 |

用二元组排序：

| 轮次 | 比较的前缀长度 | 排序后的起点 | 新排名 `rk`（按原串位置） |
|:---:|:---:|---|---|
| 初始 | 1 | `[1,3,5,0,2,4]` | `[1,0,2,0,2,0]` |
| $w=1$ | 2 | `[5,1,3,0,2,4]` | `[2,1,3,1,3,0]` |
| $w=2$ | 4 | `[5,3,1,0,4,2]` | `[3,2,5,1,4,0]` |
| $w=4$ | 8 | `[5,3,1,0,4,2]` | 排名不再变化，结束 |

注意第一轮中：

- 位置 5 的键是 `(0,-1)`，对应 `"a"`；
- 位置 1 的键是 `(0,2)`，对应 `"an"`；
- 位置 3 的键也是 `(0,2)`，对应 `"an"`。

所以位置 1 和 3 暂时同排名；到下一轮看 4 个字符时，`"anan" > "ana"`，二者才分开。

## 四、怎样把倍增写成代码

### 4.1 先写容易理解的 `std::sort` 版本

下面的版本每轮都用比较器排序二元组。外层有 $O(\log n)$ 轮，每轮排序 $O(n\log n)$，总复杂度为 $O(n\log^2 n)$。它非常适合第一次学习和检查思路。

```cpp
vector<int> build_sa_easy(const string &s) {
    int n = s.size();
    vector<int> sa(n), rk(n), next_rk(n);
    iota(sa.begin(), sa.end(), 0);

    for (int i = 0; i < n; ++i) rk[i] = (unsigned char)s[i];

    for (int w = 1; w < n; w <<= 1) {
        auto second_key = [&](int i) {
            return i + w < n ? rk[i + w] : -1;
        };
        sort(sa.begin(), sa.end(), [&](int i, int j) {
            if (rk[i] != rk[j]) return rk[i] < rk[j];
            return second_key(i) < second_key(j);
        });

        next_rk[sa[0]] = 0;
        for (int k = 1; k < n; ++k) {
            int x = sa[k - 1], y = sa[k];
            bool different = rk[x] != rk[y] ||
                             second_key(x) != second_key(y);
            next_rk[y] = next_rk[x] + different;
        }
        rk.swap(next_rk);
        if (rk[sa.back()] == n - 1) break;  // 已有 n 个不同排名
    }
    return sa;
}
```

最重要的不是比较器，而是更新排名的这一句：

```cpp
next_rk[y] = next_rk[x] + different;
```

- 二元组相同：新排名不变；
- 二元组不同：新排名比前一个大 1。

### 4.2 为什么还能优化到 $O(n\log n)$

排名已经被压成 $0,1,\dots,classes-1$ 的连续整数。整数关键字不必用比较排序，可以用计数排序。

一轮中对二元组 `(first, second)` 做稳定的基数排序：

1. 先按 `second` 计数排序；
2. 再按 `first` 计数排序；
3. 得到按二元组字典序排列的结果。

每轮 $O(n)$，一共 $O(\log n)$ 轮，所以构造 `sa` 的复杂度是 $O(n\log n)$。

### 4.3 可直接使用的完整 C++17 模板

这份模板同时构造 `sa`、`rk`、`height` 与 RMQ。后文会逐块解释 LCP 部分。代码使用 `rank + 1` 作为计数排序键，把 0 留给越界的第二段；它和讲解里的 $-1$ 是同一件事，只是方便数组计数。

```cpp
// suffix-array-full-template-begin
#include <bits/stdc++.h>
using namespace std;

struct SuffixArray {
    int n;
    string s;
    vector<int> sa, rk, height, lg;
    vector<vector<int>> st;

    explicit SuffixArray(string str) : n((int)str.size()), s(move(str)) {
        build_sa();
        build_lcp();
        build_rmq();
    }

    void build_sa() {
        sa.resize(n);
        rk.resize(n);
        if (n == 0) return;

        // 初始轮：按单个 unsigned char 计数排序。
        vector<int> cnt(max(256, n), 0);
        for (unsigned char ch : s) ++cnt[ch];
        for (int i = 1; i < 256; ++i) cnt[i] += cnt[i - 1];
        for (int i = n - 1; i >= 0; --i) {
            sa[--cnt[(unsigned char)s[i]]] = i;
        }

        int classes = 1;
        rk[sa[0]] = 0;
        for (int i = 1; i < n; ++i) {
            if ((unsigned char)s[sa[i]] != (unsigned char)s[sa[i - 1]]) {
                ++classes;
            }
            rk[sa[i]] = classes - 1;
        }

        vector<int> order(n), buffer(n), next_rk(n);
        vector<int> first_key(n), second_key(n);

        for (int w = 1; w < n && classes < n; w <<= 1) {
            for (int i = 0; i < n; ++i) {
                order[i] = i;
                first_key[i] = rk[i] + 1;  // 合法排名映射到 1..classes
                second_key[i] = (i + w < n ? rk[i + w] + 1 : 0);
            }

            auto counting_sort = [&](vector<int> &input,
                                     vector<int> &output,
                                     const vector<int> &key) {
                vector<int> count(classes + 1, 0);
                for (int x : input) ++count[key[x]];
                int start = 0;
                for (int k = 0; k <= classes; ++k) {
                    int amount = count[k];
                    count[k] = start;
                    start += amount;
                }
                for (int x : input) output[count[key[x]]++] = x;
            };

            // 稳定排序：先第二关键字，再第一关键字。
            counting_sort(order, buffer, second_key);
            counting_sort(buffer, sa, first_key);

            next_rk[sa[0]] = 0;
            int next_classes = 1;
            for (int i = 1; i < n; ++i) {
                int x = sa[i - 1], y = sa[i];
                if (first_key[x] != first_key[y] ||
                    second_key[x] != second_key[y]) {
                    ++next_classes;
                }
                next_rk[y] = next_classes - 1;
            }
            rk.swap(next_rk);
            classes = next_classes;
        }
    }

    void build_lcp() {
        height.assign(n, 0);
        int k = 0;
        for (int i = 0; i < n; ++i) {
            int rank_i = rk[i];
            if (rank_i == 0) {
                k = 0;
                continue;
            }
            int j = sa[rank_i - 1];
            while (i + k < n && j + k < n && s[i + k] == s[j + k]) {
                ++k;
            }
            height[rank_i] = k;
            if (k > 0) --k;
        }
    }

    void build_rmq() {
        lg.assign(n + 1, 0);
        for (int i = 2; i <= n; ++i) lg[i] = lg[i / 2] + 1;
        if (n == 0) return;

        int levels = lg[n] + 1;
        st.assign(levels, vector<int>(n));
        st[0] = height;
        for (int p = 1; p < levels; ++p) {
            int len = 1 << p;
            for (int i = 0; i + len <= n; ++i) {
                st[p][i] = min(st[p - 1][i],
                               st[p - 1][i + (len >> 1)]);
            }
        }
    }

    // 查询后缀 s[i..] 与 s[j..] 的 LCP；要求 0 <= i,j < n。
    int lcp_suffix(int i, int j) const {
        if (i == j) return n - i;
        int left_rank = rk[i], right_rank = rk[j];
        if (left_rank > right_rank) swap(left_rank, right_rank);

        int left = left_rank + 1, right = right_rank;
        int p = lg[right - left + 1];
        return min(st[p][left], st[p][right - (1 << p) + 1]);
    }
};
// suffix-array-full-template-end
```

构造部分的复杂度：

- 时间：$O(n\log n)$；
- 空间：`sa/rk` 与计数排序辅助数组共 $O(n)$。

后面加入稀疏表后，总空间会上升到 $O(n\log n)$。如果题目不需要任意后缀 LCP 查询，可以删掉 `lg`、`st` 和 `build_rmq()`，保留线性空间。

## 五、LCP 与 height 数组

### 5.1 LCP 是什么

LCP 是 **Longest Common Prefix**，即两个字符串的最长公共前缀长度。

```text
LCP("anana", "ana") = 3   // 公共前缀是 "ana"
LCP("nana",  "na")  = 2   // 公共前缀是 "na"
LCP("banana","ana") = 0
```

后缀数组只把所有后缀排好序；`height` 则记录排序后**相邻后缀**有多像：

$$
height[r]=LCP\big(s[sa[r]..],\ s[sa[r-1]..]\big),\quad r\ge 1,
$$

并约定 `height[0] = 0`。

`banana` 的完整表是：

| 排名 $r$ | `sa[r]` | 后缀 | 与前一名的 LCP | `height[r]` |
|:---:|:---:|---|---|:---:|
| 0 | 5 | `a` | 无 | 0 |
| 1 | 3 | `ana` | `a` | 1 |
| 2 | 1 | `anana` | `ana` | 3 |
| 3 | 0 | `banana` | 空 | 0 |
| 4 | 4 | `na` | 空 | 0 |
| 5 | 2 | `nana` | `na` | 2 |

所以：

```text
height = [0, 1, 3, 0, 0, 2]
```

### 5.2 为什么只记录相邻后缀

字典序相邻的字符串最有机会拥有较长公共前缀。更强的结论是：排名 $x<y$ 的两个后缀，它们的 LCP 等于中间所有相邻 LCP 的最小值：

$$
LCP(sa[x],sa[y])=\min_{k=x+1}^{y}height[k].
$$

## 六、Kasai 算法：$O(n)$ 构造 height

### 6.1 暴力求 LCP 的问题

如果对每一对相邻后缀都从头比较，像 `aaaaaaaa...` 这样的串会反复扫描同一段字符，最坏达到 $O(n^2)$。

Kasai 算法利用一个关键性质，把总时间降到 $O(n)$。

### 6.2 “至少还能剩下 $k-1$”

假设后缀 `s[i..]` 与它排名前一位的后缀 `s[j..]` 有长度 $k$ 的公共前缀：

```text
s[i..] = c1 c2 ... ck ...
s[j..] = c1 c2 ... ck ...
```

同时删掉第一个字符：

```text
s[i+1..] = c2 ... ck ...
s[j+1..] = c2 ... ck ...
```

剩下两串至少还有 $k-1$ 个相同字符。虽然 `s[j+1..]` 不一定恰好是 `s[i+1..]` 排名前一位的后缀，但字典序中夹在它们之间的后缀不可能让这个公共前缀更短。因此处理下一个起点 `i+1` 时，可以直接从 `max(k-1,0)` 开始比较。

这就是模板中：

```cpp
if (k > 0) --k;
```

的由来。`k` 在每次字符相等时至多增加，总共增加 $O(n)$ 次；每轮又至多减少 1，所以整个 Kasai 算法是 $O(n)$。

### 6.3 按原串位置扫描，而不是按排名扫描

Kasai 外层枚举起点 `i = 0..n-1`：

1. `rank_i = rk[i]` 找到当前后缀排名；
2. `j = sa[rank_i-1]` 找到排名前一位的后缀；
3. 从上次留下的 `k` 继续比较；
4. 写入 `height[rank_i]`；
5. 令 `k` 减 1，为下一个起点复用。

若 `rank_i == 0`，它没有前一名，令 `k=0` 并跳过。这个清零不能漏。

## 七、RMQ：任意两个后缀的 LCP

已经知道：

$$
LCP(sa[x],sa[y])=\min_{k=x+1}^{y}height[k]\quad(x<y).
$$

所以查询起点 `i`、`j` 的后缀 LCP 时：

1. 用 `rk[i]`、`rk[j]` 把原串位置变成排名；
2. 设较小排名为 `left_rank`，较大为 `right_rank`；
3. 查询 `height[left_rank+1 .. right_rank]` 的最小值。

这是静态区间最小值（RMQ）问题。模板用稀疏表：

- 预处理时间：$O(n\log n)$；
- 单次查询：$O(1)$；
- 空间：$O(n\log n)$。

特别地，如果 `i == j`，一个后缀和自己的 LCP 就是它的长度 `n-i`。

以 `banana` 为例，求 `s[1..] = "anana"` 与 `s[3..] = "ana"`：

```text
rk[1] = 2, rk[3] = 1
查询 height[2..2]
答案 = height[2] = 3
```

## 八、典型应用

### 8.1 后缀排序与模式串查找

后缀数组本身已经给出了全部后缀的排序。更有用的是：**所有以模式串 `p` 开头的后缀，在 `sa` 中一定形成一段连续区间。**

因此可以二分两次：

- 第一次找第一个“不小于 `p`”的后缀；
- 第二次找第一个“严格大于 `p` 前缀”的后缀。

```cpp
// -1: 后缀小于 p；0: 后缀以 p 开头；1: 后缀大于 p
int compare_suffix_pattern(const string &s, int pos, const string &p) {
    int k = 0;
    while (pos + k < (int)s.size() && k < (int)p.size() &&
           s[pos + k] == p[k]) {
        ++k;
    }
    if (k == (int)p.size()) return 0;
    if (pos + k == (int)s.size()) return -1;
    return s[pos + k] < p[k] ? -1 : 1;
}

pair<int, int> match_range(const string &s, const vector<int> &sa,
                           const string &p) {
    int n = sa.size(), left = 0, right = n;
    while (left < right) {
        int mid = (left + right) / 2;
        if (compare_suffix_pattern(s, sa[mid], p) >= 0) right = mid;
        else left = mid + 1;
    }
    int first = left;

    left = 0, right = n;
    while (left < right) {
        int mid = (left + right) / 2;
        if (compare_suffix_pattern(s, sa[mid], p) > 0) right = mid;
        else left = mid + 1;
    }
    return {first, left};  // 匹配位置是 sa[first..left)
}
```

每次比较最多看 $|p|$ 个字符，查询复杂度为 $O(|p|\log n)$。如果结合 LCP 优化，还能继续降低重复比较，不过初学阶段先掌握这版就够了。

### 8.2 最长重复子串

一个子串重复出现，意味着至少有两个后缀拥有这个子串作为公共前缀。拥有最长公共前缀的两个后缀，一定会在字典序中相邻，因此答案就是：

$$
\max_{r=1}^{n-1}height[r].
$$

```cpp
int best_rank = max_element(height.begin(), height.end()) - height.begin();
int best_length = height[best_rank];
int start = sa[best_rank];
string answer = s.substr(start, best_length);
```

对 `banana`，`max(height)=3`，答案是 `"ana"`，它出现在位置 1 和 3。

> 这个结论允许两次出现互相重叠。若题目要求“不重叠”，还要检查同一 LCP 分组内后缀起点的最大距离，不能只取 `max(height)`。

### 8.3 两个字符串的最长公共子串

把两个字符串拼起来：

```text
combined = A + separator + B
```

其中 `separator` 是两个原串里都不会出现的字符。构造拼接串的后缀数组后，扫描相邻后缀：

- 一个起点来自 `A`；
- 另一个起点来自 `B`；
- 它们的 `height` 就是一个跨字符串公共子串长度。

取最大值即可。

```cpp
int longest_common_substring(const string &a, const string &b) {
    char separator = '\1';  // 前提：输入中不含这个字符
    string combined = a + separator + b;
    SuffixArray index(combined);
    int split = a.size();

    auto source = [&](int pos) {
        if (pos < split) return 0;       // 来自 a
        if (pos == split) return -1;     // 分隔符后缀
        return 1;                        // 来自 b
    };

    int answer = 0;
    for (int r = 1; r < (int)index.sa.size(); ++r) {
        int x = source(index.sa[r - 1]);
        int y = source(index.sa[r]);
        if (x >= 0 && y >= 0 && x != y) {
            answer = max(answer, index.height[r]);
        }
    }
    return answer;
}
```

为什么只看相邻后缀？如果来自 `A`、`B` 的两个后缀拥有长度 $L$ 的公共前缀，那么所有以这段前缀开头的后缀在排序中连续；这段区间里一定存在一对来源不同的相邻后缀，它们的 LCP 至少也是 $L$。

### 8.4 任意两后缀的 LCP 查询

有了模板中的稀疏表，查询只需要：

```cpp
SuffixArray index(s);
cout << index.lcp_suffix(i, j) << '\n';
```

典型用途包括：

- 快速比较两个子串；
- 判断两个定长子串是否相等；
- 求字符串的周期与重复结构；
- 在一些区间 DP 或分治中快速跳过相同前缀。

例如比较 `s[l1..l1+len)` 与 `s[l2..l2+len)`：

```cpp
bool equal = index.lcp_suffix(l1, l2) >= len;
```

## 九、三个数组的关系速查

| 数组 | 下标表示 | 值表示 | `banana` |
|---|---|---|---|
| `sa[r]` | 字典序排名 $r$ | 后缀起点 | `[5,3,1,0,4,2]` |
| `rk[i]` | 后缀起点 $i$ | 字典序排名 | `[3,2,5,1,4,0]` |
| `height[r]` | 排名 $r$ | 第 $r$ 名与第 $r-1$ 名后缀的 LCP | `[0,1,3,0,0,2]` |

必须记住的式子只有三个：

$$
sa[rk[i]]=i,
$$

$$
height[r]=LCP(sa[r],sa[r-1]),
$$

$$
LCP(sa[x],sa[y])=\min_{k=x+1}^{y}height[k]\quad(x<y).
$$

## 十、复杂度总结

| 部分 | 时间复杂度 | 空间复杂度 |
|---|:---:|:---:|
| 直接比较完整后缀排序 | $O(n^2\log n)$ | 视实现而定 |
| `std::sort` 倍增 | $O(n\log^2 n)$ | $O(n)$ |
| 计数排序倍增 | $O(n\log n)$ | $O(n)$ |
| Kasai 构造 `height` | $O(n)$ | $O(n)$ |
| 稀疏表预处理 | $O(n\log n)$ | $O(n\log n)$ |
| 单次任意后缀 LCP | $O(1)$ | — |
| 单次模式串查询 | $O(|p|\log n)$ | — |

## 十一、最常见的七个错误

1. **把 `sa` 和 `rk` 写反**：`sa[排名]=位置`，`rk[位置]=排名`。
2. **越界第二关键字与合法排名冲突**：讲解中用 $-1$；计数排序模板中用 0，并把合法排名整体加 1。
3. **每个后缀都无脑增加新排名**：只有相邻二元组不同，新排名才加 1。
4. **忘记 `height[0]=0`**：最小后缀没有排名前一位。
5. **RMQ 区间少加或多加 1**：排名 $x<y$ 时查 `height[x+1..y]`。
6. **拼接字符串时分隔符出现在原串中**：分隔符必须唯一，否则 LCP 可能跨过边界。
7. **模式串二分拿整个后缀比较**：匹配只关心后缀前 $|p|$ 个字符，模式串耗尽就应返回“匹配”。

## 结语

后缀数组真正做的事并不神秘：**把所有后缀放进字典序坐标系里。**

- `sa` 告诉你每个排名对应谁；
- `rk` 告诉你每个后缀站在哪里；
- `height` 告诉你相邻后缀有多像；
- RMQ 把“相邻有多像”扩展成“任意两个后缀有多像”。

倍增法也不是凭空出现的黑科技。它只是把一个长比较拆成两个已经算过的短排名，再让已知长度不断翻倍。只要你能自己手推完 `banana`，那份看起来很长的模板，就已经不再是需要死记的咒语了。
