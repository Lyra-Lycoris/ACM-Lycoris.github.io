# 字符串后缀数组教程文章设计

## 目标

为刚开始学习字符串算法的读者撰写一篇中文教程，使读者能够：

- 理解后缀数组中 `sa`、`rk`、`height` 三个数组的含义与关系；
- 理解并独立复现后缀数组的倍增构造方法；
- 使用 Kasai 算法在线性时间内构造 LCP 数组；
- 使用稀疏表回答任意两个后缀的 LCP 查询；
- 将后缀数组用于模式串查找、最长重复子串和两字符串最长公共子串。

文章面向字符串算法初学者，但保留可直接用于算法竞赛的 C++17 实现与复杂度分析。

## 叙事结构

文章采用概念递进结构，以字符串 `banana` 贯穿全文：

1. 从后缀与字典序出发，手工列出并排序 `banana` 的全部后缀。
2. 定义 `sa` 和 `rk`，通过互为逆映射的关系消除下标混淆。
3. 分析直接比较完整后缀的暴力方法，引出倍增思想。
4. 将长度为 `2w` 的前缀拆成两个长度为 `w` 的部分，以排名二元组完成排序。
5. 展示朴素 `std::sort` 版本，再给出计数排序优化后的竞赛模板。
6. 定义 LCP 与 `height`，推导 Kasai 算法。
7. 利用 `height` 区间最小值和稀疏表回答任意两后缀 LCP。
8. 通过四类典型应用把数组含义落到具体问题中。
9. 用速查表、复杂度表与易错点收束全文。

## 算法与代码范围

代码统一采用 C++17、0-based 下标，并显式说明空的第二关键字使用 `-1`。

文章包含以下独立代码段：

- 易理解的 `std::sort` 倍增实现，复杂度为 `O(n log^2 n)`；
- 使用计数排序的倍增模板，复杂度为 `O(n log n)`；
- Kasai LCP 构造，复杂度为 `O(n)`；
- 稀疏表 RMQ，预处理 `O(n log n)`、单次查询 `O(1)`；
- 模式串二分查找、最长重复子串、两字符串最长公共子串的核心写法。

每段代码都与正文采用相同的数组定义，避免同一篇文章中切换下标体系。

## 典型应用

1. **后缀排序与模式串查找**：利用所有包含模式串的后缀在 `sa` 上连续这一性质做两次二分。
2. **最长重复子串**：答案为 `max(height)`，并解释重叠是否允许对答案的影响。
3. **两字符串最长公共子串**：拼接 `A + separator + B`，检查排序后来自不同原串的相邻后缀。
4. **任意两后缀 LCP**：将两个起点转换为排名，对 `height` 区间做 RMQ。

## 正确性与复杂度说明

- 倍增法通过归纳说明：若排名正确表示长度 `w` 的前缀顺序，则排名二元组正确表示长度 `2w` 的前缀顺序。
- Kasai 算法解释相邻起点移动后 LCP 至少减少一的性质。
- RMQ 说明两个排名之间所有相邻 LCP 的最小值，正是两个端点后缀的 LCP。
- 分别列出暴力、`std::sort` 倍增、计数排序倍增、Kasai 和 RMQ 的时间与空间复杂度。

## 易错点

- 混淆 `sa` 与 `rk` 的自变量；
- 第二关键字越界时与合法排名冲突；
- 新排名只在二元组变化时增加；
- `height[0] = 0` 的边界；
- RMQ 查询区间应为排名较小者加一到排名较大者；
- 拼接两个字符串时，分隔符必须不出现在原字符串中；
- 模式串二分时只比较模式串长度范围。
